# Tic-Tac-Toe

A classic, browser-based Tic-Tac-Toe game featuring a clean UI, interactive gameplay, and a reset function. Built entirely with vanilla web technologies.

🎮 **[Play the Live Game Here](https://Richi-SM.github.io/tic-tac-toe-js/)**

## Features
* 3x3 interactive grid
* Alternating turns for X and O
* Real-time game reset functionality 

## Tech Stack
* HTML5
* CSS3
* JavaScript

## Local Setup
1. Clone this repository.
2. Open `index.html` in any modern web browser to play.
